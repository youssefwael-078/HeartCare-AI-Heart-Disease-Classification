📋 About This Project

This project applies supervised machine learning to predict whether a patient has heart disease based on clinical measurements. It trains three classification models — Logistic Regression, Random Forest, and Support Vector Machine — and uses GridSearchCV to find the optimal hyperparameters for each. The best model is then deployed in this Flask web interface for interactive prediction.
